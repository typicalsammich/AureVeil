Build a complete, production-quality full-stack web application for an art discovery, inspiration, and marketplace platform.

The core idea:

Users can upload artwork, photography, illustrations, tattoo designs, paintings, digital art, concept art, sketches, graphic design, 3D artwork, etc. Other users can browse the platform to discover art, find artists with similar styles, save inspiration, commission artists, or purchase artwork.

Think of the discovery behavior of Pinterest, the creator/shop functionality of Etsy, the portfolio aspect of Behance/ArtStation, and modern social discovery platforms, but DO NOT copy the visual design of any of those websites.

The product should feel like its own polished startup.

A major feature is AI-assisted visual discovery. A user should eventually be able to upload an image or select existing artwork and find artwork or artists with a similar visual style.

Users should also receive personalized recommendations based on artwork, styles, subjects, colors, artists, and categories they interact with.

This MUST be a functional full-stack application. Do not create fake buttons, fake account systems, fake checkout pages, or UI elements that do nothing.

==================================================
OVERALL DESIGN DIRECTION
==================================================

The website should look like it was designed by a very good human product designer in 2026.

Do NOT make it look like a generic AI-generated SaaS website.

Avoid:
- giant gradient hero sections
- glowing blobs
- excessive rounded cards
- random floating glassmorphism elements
- huge amounts of empty space
- generic icon + title + paragraph feature grids
- excessive gradients
- overly rounded pill buttons everywhere
- fake statistics
- generic AI-generated marketing copy
- endless boxes inside boxes
- overly symmetrical layouts
- every section having the exact same structure
- purple/blue AI startup styling
- excessive drop shadows
- unnecessary animations
- emojis as interface icons

The actual artwork should be the visual focus.

Use a sophisticated neutral design system.

Suggested aesthetic:
- warm white / very light gray primary background
- near-black text
- dark navigation elements
- subtle borders
- restrained accent color
- artwork provides most of the color
- premium typography
- strong editorial layout
- clean spacing
- highly polished hover states
- subtle motion only where appropriate

The interface should feel like a combination of an editorial art magazine, creative portfolio site, and modern marketplace.

Desktop and mobile layouts must both feel intentionally designed.

Use responsive breakpoints instead of simply shrinking the desktop design.

Mobile navigation should be clean and native-feeling.

Do not use a custom circle cursor.

Use a normal cursor.
